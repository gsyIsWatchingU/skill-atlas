不用装任何东西，在你自己的浏览器里跑一遍

选一个目录，浏览器会把这个目录的读取权限交给我们——只是读取。 分析全程在本地完成，报告直接渲染在这页上，一个字节都不会发到服务器，也不会写入任何文件。

选项目目录时，只读取该项目下的 .agents/skills 与 .codex/skills。 选 Skill 目录时，会向下递归查找所有含 SKILL.md 的文件夹。

不知道该选哪个目录？

复制下面的路径，粘到文件管理器（Windows 资源管理器 / macOS Finder 的"前往文件夹"）的地址栏回车， 就能跳到那个目录。然后回来点"选择 Skill 目录"选中它。

更简单的方式：直接选中它的上一层目录（比如整个用户目录），我们会向下自动找出所有 Skill—— 这就是"扫描"，不需要任何脚本，只是范围大时慢一些。
